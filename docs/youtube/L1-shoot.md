# L1 — Shoot list (actions only)

Just the taps, in the order you record them. **Don't speak while filming.**
The words are in `L1-voiceover.md`, recorded afterwards over the footage.
On-screen text and blurs are in `L1-edit.md`.

Each clip has a **Start on** and a **Stop when**. Do the taps slowly, about
twice as slow as feels natural, and **hold 2 seconds** at the start and end of
every clip. The edit can cut dead air, but it can't add it.

Record the whole list twice. Use the better take.

---

## Before you start

**Once per shoot day**
- [ ] DND on, battery >80%, portrait, orientation lock on
- [ ] Gmail signed in on the phone, inbox cleared of Google's setup emails
- [ ] `demo-squad.md` open on a second screen
- [ ] Badge image saved on the phone
- [ ] Admin portal open on your laptop (for the invite in clip 4)

**Before every take**
- [ ] Clear Level's site data on the phone: Chrome → ⋮ → Settings → Site
      settings → All sites → `app.keepthingslevel.com` → **Delete data**.
      Reload; you should see Coach sign-in.
- [ ] Pick this take's demo address: `yourdemo+takeN@gmail.com` (new N each
      take, so Level treats it as a new coach)
